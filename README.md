# ÆTHER

A motion-controlled algorithmic sound playground. Built with Tone.js, HTML Canvas, and vanilla JavaScript.

## Features

- **Touch Pads** — 4x4 grid of playable synth pads with multi-touch and keyboard support
- **Motion FX** — Tilt your device to sweep filters, reverb, and pan. Shake for glitch effects
- **Step Sequencer** — Visual beat grid with Euclidean rhythm generators
- **Live Code Editor** — Mini-notation pattern language inspired by Strudel/TidalCycles
- **Audio-Reactive Visualizer** — 4 modes: Particles, Waveform, Spectrum, Nebula

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:5173` and click "Enter" to start.

## Build

```bash
npm run build
```

Static files output to `dist/`.
